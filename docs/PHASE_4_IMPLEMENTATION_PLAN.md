## 1. 交付範圍

已確認本階段包含：

1. 使用者手動設定運動秒數、休息秒數及總組數，不自動推薦強度或產生課表。
2. 組別開始語音由「第 x 組，開始」改為「準備，開始」。
3. 所有休息提示統一為「休息」；準備與完成提示、最後 5 秒節拍音沿用，不新增逐秒人聲倒數或開始音效。

本階段不包含背景／鎖屏持續計時與跨程序恢復評估。沿用退背景或 inactive 安全暫停、回前景後手動繼續，以及程序終止後未完成訓練不留紀錄的規則。

固定時間提醒、結算 Lottie、新運動種類、能力處方、身體數據、帳號／同步、挑戰歷史與訓練參數歷史不納入本階段。核心程式已交付；語音檔為既有素材衍生草稿，其權利、實際文字與聽感尚未確認，完整 Phase 4 驗收未成立。

## 4. 建議實作設計

以下記錄已交付的最小實作；素材草稿與其驗收限制另見 `ASSETS_LICENSES.md`。

### 4.1 參數與計時推導

- 以一個簡單的訓練參數型別傳遞運動秒數、休息秒數與組數，取代固定值；不建立模式／課表引擎。
- 在 `tabata.ts` 依參數建立該次階段及排程，snapshot、音訊事件與完成判定共用同一份資料，避免各自計算出不同時點。
- 最後一組後不休息，正式總秒數為「運動秒數 × 組數 + 休息秒數 ×（組數 − 1）」；含準備總秒數再加 3。
- 本次訓練參數在按「開始」時確定並用於該次階段與排程。開始後離開設定畫面，暫停仍停留在訓練中畫面，沒有修改參數入口；不為開始後修改設定新增攔截邏輯或不可達操作測試。暫停／繼續及完成紀錄保存重試沿用當次排程，不重建訓練時長。
- 預設 20／10／4 必須仍為七階段、110 秒正式訓練與 113 秒全流程。
- 沿用原有 elapsed time 推導、100ms tick 與既有音訊調度規則；不改為背景服務，不另建計時持久化。

### 4.2 設定與讀取

- 已新增 `src/data/workout-preferences.ts` 與單筆本機設定資料，沿用現有 SQLite repository 風格。
- 資料庫升級只新增設定所需結構與初始資料，保留完成、休息、挑戰、個人資料及音訊設定；不要預建歷史欄位。
- 三項參數使用已確認範圍與步進的加減控制；按「開始」時單次提交三項參數，不另加儲存按鈕。只調整後離開不保存，不靜默改值或另存部分欄位。
- 已保存值與編輯草稿分開；下次進入訓練頁帶入上次按「開始」時成功保存的設定。設定保存失敗時，原保存值不變，仍使用當次設定開始訓練，不顯示失敗或成功提示。設定讀取失敗時使用預設 20／10／4，不提示，仍可調整並開始；讀取失敗本身不覆寫保存值，之後按「開始」仍依已確認規則保存當次設定。這些規則不改變完成紀錄保存的既有錯誤與重試流程。
- 訓練頁開始前的流程區已改為參數控制，重用共用按鈕、theme tokens 與資料載入慣例；未在既有設定 dialog 新增訓練欄位，也未新增通用設定框架或依賴。

### 4.3 語音與提示音

- 共用開始事件已接入已定案的運動開始邊界，不依組數拼接音訊或產生任意組數音檔。現有 WAV 是既有音訊衍生草稿，實際錄音文字、來源／授權與聽感尚未驗收。
- 開始事件排在每組運動開始邊界，不增加計時等待或每組 3 秒準備；實際語音是否符合預期仍待人耳驗收。
- 音訊仍受既有「提示語音」Switch 控制；背景音樂保持獨立。每個運動／休息階段最後 5 至 1 秒沿用現有節拍音，不新增逐秒人聲倒數資產或排程。
- 每次進入休息階段使用同一個「休息」事件；舊組別與休息語音 key／mapping／caller 已清理。現有 WAV 為既有素材衍生草稿，不能據此宣稱錄音文字符合預期或已通過聽感驗收。
- 素材文字、來源與授權仍待確認；`ASSETS_LICENSES.md` 記錄目前衍生方式與限制，不得將舊錄音當作新文案驗收通過。

### 4.4 畫面與完成紀錄

- 訓練頁「Tabata 訓練」文字已改為「訓練」。開始前流程區直接呈現可調整的當次參數，已移除「固定流程」及組數後的「最後一組不休息」文字；計時組數分母與訓練相關無障礙名稱使用當次參數，不讓自訂流程繼續顯示固定四組或固定兩分鐘。
- 加減按鈕帶有果凍感，沿用既有設計語言的柔和圓角、淡色實心表面與輕微按壓縮放；觸控區至少 44 × 44，數值與停用狀態清楚可辨。
- 維持既有像素小人、動作節奏與完成回饋，僅隨當前運動／休息狀態切換。
- 完成紀錄是否成立依第 3 節定案；沿用日期鎖定、原子保存／休息替換、重試及一次性完成回饋。
- 一般訓練、再做一次與讀取今日紀錄失敗後的不記錄訓練，使用同一套已定案參數流程；紀錄模式保持原有差異。
