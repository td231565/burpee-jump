## 1. 交付目標

讓完整四組訓練結束時有清楚、短暫的視覺與觸覺回饋，並交付像素風小人的簡化波比跳循環，帶出輕微電玩感。既有完成語音與完成音效已交付，本階段以整合和驗收為主，不另製作第二個完成音效。訓練中的角色動畫是本階段必要交付，須通過倒數可讀性、暫停行為及雙平台效能驗收；未通過就持續修正，不以移除角色作為完成方案。

## 2. 範圍與行為契約

### 2.1 完成動畫

- 一般每日訓練：完整四組結束後仍先依既有流程保存；保存成功才顯示「已記錄」及一次輕量完成動畫。保存失敗、重試中或放棄紀錄時不顯示已記錄動畫；重試成功只播放一次。
- 一般訓練在計時完成後的儲存中及儲存失敗待重試狀態顯示小人的靜態站姿；只有保存成功才切換至展示肌肉與日出的完成畫面。放棄紀錄後離開，不播放完成動畫或震動。
- 不記錄訓練（包含「再做一次」）：完整四組結束後顯示「本次訓練已完成」、同一套像素小人與日出動畫及一次震動，不使用「已記錄」文案，不寫入完成紀錄。
- 完成畫面使用訓練中的同一個像素小人，雙臂向兩側平舉並彎曲、展示肌肉；角色以卡通化、少量肌肉線條表達得意，不在完成瞬間變成健美體型。背後以日出作為低對比背景。角色與日出只作短暫、一次性的完成動畫，完成文字與返回操作始終清楚可見；素材須為原創，不使用既有遊戲角色或可辨識造型。
- 小人與日出約 1 秒進場並播放一次，之後停在靜態完成姿勢；返回操作從完成畫面出現時即可使用，不等待動畫播完，也不延遲資料刷新或挑戰結算。系統啟用 Reduce Motion 時直接顯示小人姿勢與日出的靜態完成狀態，仍保留一次完成震動。

### 2.2 音效與震動

- 沿用現有「完成」語音後的一次完成音效及既有「提示音效」開關；本階段不新增完成音檔、不重播或疊加第二個音效。
- 完成音效維持現有「計時完成」時點，與保存成功後的動畫和震動形成兩個明確時點。保存失敗時可先聽到完成音效，但不顯示已記錄動畫或觸發震動；重新儲存成功時也不重播完成語音或音效。不記錄訓練沿用同一個完成音效。
- 完成動畫出現時觸發一次短促、溫和的震動：一般訓練在保存成功時，不記錄訓練在完整計時結束時。保存失敗重試成功只震動一次；取消、提前離開及單純進入待儲存狀態不震動。
- 震動屬視覺完成回饋的輔助，獨立於「提示音效」開關；使用者關閉提示音效時仍保留完成震動。本階段不新增震動開關，也不改變「導引語音／提示音效／背景音樂」三個既有開關的意義；若系統或裝置不提供震動，完成流程仍照常進行。

### 2.3 訓練中動畫

- 製作一個原創像素風小人，以少量清楚的關鍵姿勢循環呈現簡化波比跳：站立、蹲下撐地、雙腳向後成棒式、回到蹲姿、起身小跳。角色只放在倒數卡外的留白處，尺寸與對比低於倒數；維持簡單輪廓與少量顏色，營造輕微電玩感，不使用既有遊戲角色或可辨識造型。
- 一般每日訓練與兩種不記錄訓練（「再做一次」、今日紀錄讀取失敗後直接開始）使用同一套角色動畫。剛進入計時畫面、尚未按「開始」以及 3 秒準備倒數期間都顯示靜態站姿；正式運動階段才連續播放簡化波比跳循環。10 秒休息階段維持站姿，以少量幀格呈現胸肩微幅起伏的呼吸感，不繼續做波比跳。角色動態不跟隨每秒倒數、不指示使用者呼吸節奏、不計算動作次數，也不改變倒數數字、組數、按鈕、背景及計時邏輯。
- 小人是訓練陪伴角色，不承擔動作教學或計時指示；畫面不為小人加入動作名稱、次數或教學提示。運動與休息仍靠大字階段名稱、倒數及既有語音辨識；是否可能被當成跟做示範，不作為本階段的驗收或移除條件。
- 手動暫停、安全暫停、離開畫面或 Reduce Motion 開啟時停止波比跳與呼吸循環並呈現靜態姿勢；繼續後依當前運動或休息階段恢復對應動態。階段切換不得重設倒數或音訊排程。
- 在 iOS 與 Android 實機驗證。若倒數辨識變慢、明顯掉幀、閃爍或暫停後仍運動，調整角色尺寸、幀格或播放方式並重新驗收；未通過前不得將 Pre-Phase 3 標為完成，不以移除角色替代。

### 2.4 不納入

- Phase 3 的通知、個人理由與障礙備案，以及挑戰結算的 Lottie 動畫。
- 新訓練模式、計時秒數或組數調整、背景計時、儲存規則與挑戰結算規則變更。
- 額外音訊偏好、震動設定、完成動畫變體、徽章收藏、可互動角色或新進度資料。

## 3. 實作順序

1. 固定兩條正常完成路徑與儲存失敗重試路徑的回饋時點，確認既有完成音效只觸發一次。
2. 實作一次性完成動畫與 Reduce Motion 靜態呈現；不改完成頁的文案、保存與返回操作。
3. 接入一次性震動，並確認沒有震動能力時不影響完成流程。
4. 在倒數卡外製作像素風小人的簡化波比跳循環，驗證運動／休息、暫停、背景、恢復、階段切換與 Reduce Motion；達不到第 4 節門檻就修正並重新驗收。
5. 更新 `PRODUCT_SPEC.md`、`DESIGN.md` 與必要的產品紀錄，記下實際交付效果與驗收結論。

## 4. 驗收

- 一般訓練保存成功後只出現一次已記錄動畫與震動；保存失敗不誤稱已記錄，重試成功只回饋一次。
- 訓練中角色在儲存中及待重試時維持靜態站姿，不提前播放完成姿勢。
- 不記錄訓練顯示本次完成回饋，但不增加或更改任何完成紀錄；取消與提前離開沒有完成回饋。
- 完成語音及音效仍依既有音訊偏好與時序各播放一次；動畫與震動不使訓練、儲存、返回或結算等待額外時間。
- 完成動畫約 1 秒播放一次後停在完成姿勢，返回操作從畫面出現時即能使用。
- Reduce Motion 開啟時所有新動畫均為靜態，完成畫面仍有小人、日出與一次震動；大字級、螢幕閱讀器及窄螢幕下完成文字、倒數與操作仍可辨識。
- 訓練中的像素小人須在 iOS／Android 實機、開始前、準備倒數、運動與休息階段、手動與安全暫停、切換階段及返回前景後檢查；開始前與準備倒數為靜態站姿，休息只呈現微幅呼吸、不繼續波比跳，倒數在一般觀看距離可立即辨識，動畫無可察覺卡頓、閃爍或殘留。未通過則修正並重新驗收。
- 一般每日訓練、「再做一次」及今日紀錄讀取失敗後直接開始的不記錄訓練，使用相同的訓練中角色狀態與動畫。
- 以公開互動與音訊協調邊界驗證回饋時點及「只一次」行為；視覺手感、震動強度與實機效能由人工驗收。

Done 條件：完成動畫、既有完成音效整合、震動與訓練中像素小人動畫均通過上述驗收；不得以移除訓練中角色作為完成條件。
