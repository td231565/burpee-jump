# 將挑戰結算設為一次性快照

Phase 2 的挑戰結束後只顯示一次「已完成／未完成」，並保存已結算標記，不保存結果歷史。結算前先處理合法的最後一天補登；結算後每日休息紀錄仍可在原期限內補登或取消，但只影響日曆與連續訓練天數，不改變曾顯示的結果。這讓挑戰只承擔當下回饋，避免結算與可編輯每日紀錄相互牽動；代價是結算當下的結果可能與後來的每日紀錄不同。

顯示滿版結算畫面前先持久化已結算標記。即使 App 在標記成功後、畫面出現前中斷，下次也不重顯；這選擇「最多呈現一次」而非保證使用者看見結果，以免關閉 App 後重複回饋。畫面是否看過、跳過或關閉不另存狀態。

標記寫入失敗不延長舊挑戰的固定週期，也不阻擋建立新挑戰。下次進入前景時重試寫入；若使用者已開始新挑戰，只補記舊挑戰已結算，不延後顯示舊結果，避免舊回饋打斷新週期。

寫入失敗不建立結果快照。若尚未開始新挑戰，重試成功時依當下每日紀錄判定；因此失敗與重試之間的合法補登或取消可能改變最後呈現的結果。
