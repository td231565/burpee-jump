## 1. 交付目標

在既有「首頁 → 四組計時 → 保存 → 日曆」閉環上加入固定 7／14／30 天挑戰、限次休息、隔日補登、復歸與一次性結算。每日訓練及休息紀錄獨立於挑戰結果；不新增忙碌模式或單組完成。

挑戰資料、每日紀錄、剩餘額度與是否已結算必須在重啟後一致。結算結果僅於當下顯示一次，不提供歷史結果或結算後重算。

## 2. 已定案的資料與操作契約

- 挑戰在建立當地日開始，連續 7／14／30 日，休息不順延。週期內不能新建挑戰；結束隔天先結算舊挑戰，再可建立新的。建立當天已有四組完成紀錄時直接計入。
- 每日只有已完成、休息日、今天待完成、過去無紀錄四種可見狀態，未來日期無狀態。沒有紀錄的過去挑戰日仍顯示無紀錄。已完成須為完整四組成功儲存；同日「再做一次」不記錄。
- 休息額度為 7／14／30 天各 1／2／3 次。當日休息可於當日結束前取消；昨天補登休息可於補登當日結束前取消。取消退還額度。已儲存訓練的日期不可設定休息。對外不區分休息來源，僅保存設定時間判斷取消期限。
- 連續訓練天數只數已完成日；休息日維持連續性但不加一天，無紀錄日中斷。今天待完成時先顯示截至昨天的天數。
- 最後一天結束後於隔天 00:00（App 在前景）或下次進入前景時處理結算；若可補登最後一天，先詢問再顯示一次結果。跨午夜仍在訓練或待儲存時延後處理。結算後的合法補登或取消只更新每日紀錄和連續天數，不修改已顯示結果。
- 日曆只標示進行中的挑戰範圍、起迄日、剩餘休息額度與連續訓練天數；不顯示百分比、分類統計、歷史挑戰結果或每日挑戰成敗。跨月沿用單一月曆。

D-053 覆蓋 D-001 的補登休息專屬標記、D-003 的百分比與結算後重算，以及早期忙碌模式的範圍。D-007、D-016 的當地日與按「開始」鎖定歸屬日規則仍有效。

## 3. 範圍

### 納入

- 三種固定挑戰週期、當天建立、週期內不可重建及結束隔天可建立下一個。
- 完整四組訓練與原有日期鎖定、儲存重試、不記錄再次訓練路徑。
- 限次休息、當日設定／取消、昨天補登／取消及額度退還。
- 漏做後的溫和復歸、連續訓練天數與每日狀態。
- 進行中挑戰日期範圍標示、起迄日、剩餘休息額度與一次性二元結算。
- SQLite 持久化、跨日／跨月／重啟一致性、iOS／Android 無障礙驗收。

### 不納入

- 忙碌模式、最低完成、完成百分比、週期進度數字、模式分類統計、挑戰結果歷史畫面、結算後重算。
- Phase 3 通知、震動、Lottie、理由或障礙備案；Phase 4 自訂秒數、組數與背景計時；之後階段的身體數據、帳號、同步或社交。
- 任意歷史日補登、超額休息、同日再次訓練統計；現有「再做一次」仍不記錄。

## 5. 垂直切片與驗收

每片先寫公開行為測試，再做最小實作；前片通過後才進下一片。

### Slice 0：資料契約與案例

1. 固定日期狀態與合法操作表；驗證今天待完成、過去無紀錄、已完成、休息日及未來無狀態。
2. 用 7／14／30 天例子固定起迄日、1／2／3 次額度、跨月、跨午夜、取消與退還。
3. 固定一次性結算及結算後每日紀錄可變的案例，涵蓋結算前補登、結算後補登／取消、跨午夜待儲存。
4. 保留既有 daily_completions，完成 schema 變更、舊資料備份與升級驗證步驟。

**驗收：** 每個例子可唯一判定每日顯示、剩餘額度、連續天數、結算時點與當下結果。

### Slice 1：建立挑戰與持久化

- 首頁提供 7／14／30 天選擇與建立入口；建立當天是第 1 天，顯示起迄日和額度。
- 同期第二個挑戰不可建立；結束隔天須先結算舊挑戰。已存在的當日四組完成紀錄直接計入。
- 交易及 repository 測試涵蓋重啟、既有完成紀錄保留及週期日期。

### Slice 2：完整訓練與每日紀錄

- 挑戰期間沿用唯一四組訓練流程，不出現模式選擇。保存成功後日曆顯示已完成；失敗時不計入，重試成功僅一筆。
- 同日「再做一次」不寫入或升級每日完成紀錄；跨午夜歸屬日沿用 D-016。

### Slice 3：限次休息與取消

- 只能在尚未儲存訓練的挑戰日設定休息；休息消耗一次額度，不延後結束日。
- 當日結束前可取消並退還額度；設定時間支援期限判斷，重啟後一致。
- 日曆與日期詳情以文字加圖示／形狀區分已完成與休息日，不只靠顏色。

### Slice 4：補登、取消與復歸

- 只有昨天、沒有完成紀錄且原挑戰有額度時可補登；確認前明示額度與固定結束日。補登當天結束前可取消退額度。
- 補登與當日休息在日曆都只顯示「休息日」；更早日期不能補登，已有完成紀錄的日期不能改休息。
- 昨天無紀錄時首頁提供溫和復歸入口；連續訓練天數在休息與無紀錄情境正確重算，過去完成紀錄保留。

### Slice 5：日曆與一次性結算

- 日曆頁只顯示進行中挑戰起迄日、剩餘額度、當月可見的期間標記，以及「已連續訓練 x 天」。結束後移除期間標記，不提供歷史挑戰結果。
- 最後一天結束隔天，先詢問合法補登，再依當下日期紀錄顯示一次已完成／未完成；顯示後保存已結算標記，不因重啟重顯。
- 結算後合法補登及取消只更新每日紀錄與連續天數，不改動一次性結果。跨午夜仍在進行或待儲存的訓練延後結算。
- 跨月仍使用 D-004 的單一月曆；月份切換、回到今天、日期詳情與每日狀態一致。

### Slice 6：雙平台與回歸驗收

- iOS、Android 實機完成建立挑戰、四組完成、當日休息／取消、昨天補登／取消、漏做復歸及一次性結算。
- 驗證小螢幕、大字級、VoiceOver／TalkBack 能理解四種每日狀態、挑戰範圍、額度與操作前後的日期。
- 驗證裝置日期／時區與 D-007、D-016；驗證既有紀錄、跨午夜保存、暫停取消、儲存失敗重試及不記錄再次訓練無回歸。
