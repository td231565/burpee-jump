## 2. 行為契約

### 2.1 訓練小人與 Reduce Motion

- 系統開啟減少／關閉動態效果時，正式運動仍播放波比跳，休息仍播放呼吸循環。
- 開始前、3 秒準備、手動／安全暫停、儲存中與待重試仍呈現靜態站姿；離開停止動畫，繼續後依目前階段恢復。
- 暫停後繼續時，角色從目前運動／休息階段的動畫起點（站姿）重播，不保留暫停前的姿勢或作動進度；訓練倒數仍從暫停處接續。
- 例外只適用訓練陪伴角色；完成進場、首頁 GO 與挑戰結算仍遵循既有 Reduce Motion 規則。

### 2.2 每個作動延長 0.2 秒

- 運動每姿勢由 300ms 改為 500ms，五姿勢完整循環為 2.5 秒。
- 休息每姿勢由 600ms 改為 800ms，兩姿勢完整循環為 1.6 秒。
- 不改計時、階段、組數與音訊排程。

### 2.3 按鈕依內容決定寬度

- 專案文字 Button 不再因父層 stretch 或 width: 100% 滿版，保留各頁既有排列與對齊。
- 每側水平留白最多為 spacing.lg（24dp），一般字級以 24dp 為目標；大字級時優先縮減左右留白，以保留單行文字。約 1.3 字僅描述一般 18dp 字級下的視覺比例，不作動態留白公式。
- 使用 React Native 邏輯單位（dp／iOS point）與 theme tokens，不使用實體像素換算。
- 最大寬度不超過可用區域，按鈕文字不換行，觸控區至少 44 × 44；保留 disabled 與 pressed 行為。
- 縮減左右留白後，文字本身仍超過可用寬度時，允許縮小按鈕文字至可完整顯示；維持單行、不裁切。此縮字規則僅適用文字 Button，其他文字仍依系統字級放大。
- IconButton、GO 與 tab 觸控區不套用文字寬度規則；檢查所有 Button caller 的滿寬覆寫。

### 2.4 首頁今日已完成

- 放大「今日已完成」，以 typography.fontSize.hero（32）作初始視覺候選，於窄螢幕與大字級確認最終大小。
- 在文字下方放既有 celebrate 肌肉小人靜態圖，已確認採用，為必要交付；重用素材，不加日出背景、進場、震動或音訊。
- 圖片只在今日 completed 狀態出現，作裝飾並從螢幕閱讀器隱藏，不擠掉「再做一次」及其他操作。
- 「再做一次」必須在首頁初始可視區內、不用捲動即可看見；小螢幕或大字級下空間不足時，優先縮小裝飾小人，必要時隱藏，保留放大的完成文字與操作。
- 提供候選畫面確認圖片尺寸與佈局，採用與否已定案；依上述空間優先順序驗收一般、小螢幕與大字級畫面。

### 2.5 底部導覽無白底

- 共用 bottomNav 改透明底，露出既有頁面背景；首頁與日曆使用一致外觀。
- 保留固定位置、safe area、選取狀態、文字對比與觸控區，不新增背景卡片。

### 2.6 日曆挑戰入口固定於底部

- 將「設定挑戰週期」由日曆 ScrollView 網格後方移至日曆頁固定底部、共用 nav 上方。
- 採捲動內容與底部操作分區，不遮住日曆；28／35／42 格月份切換時按鈕不跳位。
- 維持 challengeStatus === 'none' 才顯示，點擊仍開啟既有挑戰建立頁，不新增其他狀態入口。
- 小螢幕及大字級時日曆可捲動、底部操作可存取。

### 2.7 設定 dialog

- 「個人資料」至「暱稱（選填）」、標籤至 input，兩段間距各增加 spacing.xs（4 邏輯單位）；不改其他區塊間距。
- 移除下方「更新暱稱」文字按鈕，在 input 右方同一列放既有 IconButton 與 lucide Check；input 使用剩餘寬度。
- 無障礙名稱維持「更新暱稱」，觸控區至少 44 × 44；保留明確提交、保存中禁用、成功／失敗訊息與既有空白暱稱處理，不改為輸入即保存。
- 「導引語音」與「提示音效」合併為單一「提示語音」Switch，一次切換同步保存 voice_enabled、cues_enabled 為相同值。
- 沿用現有 SQLite 欄位及單次 updateAudioPreferences，不新增合併欄位或通用設定架構。背景音樂維持獨立，切換仍立即保存，下一次進入訓練套用。
- 關閉提示語音時同步關閉導引語音、準備／階段提示與完成音效；完成震動維持獨立。
- **已確認（2026-10-01）：**App 尚未發布，仍在開發階段，忽略舊音訊設定；不建立舊值合併、相容或資料遷移規則。新安裝提示語音與背景音樂預設皆開啟；驗收不涵蓋舊開發資料兩欄不一致的情境。

### 2.8 首頁歡迎詞

- 有暱稱時改為「Hi {暱稱}」，移除逗號，Hi 後保留一個空格。
- 無暱稱沿用既有不顯示歡迎詞規則。
