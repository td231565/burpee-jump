# 波比跳日曆

本文件定義波比跳日曆產品中，日期與每日訓練狀態的共同語言，避免把沒有資料誤解為使用者失敗。

## Language

**首次引導已呈現**：
本次安裝的首次引導已開始向使用者顯示；開始呈現時即永久標記，之後不再自動顯示。它不代表使用者已輸入暱稱、完整閱讀教學或同意安全資訊，也不因未來內容版本改變而重設。
_Avoid_：本版引導完成、已讀教學、安全同意

**個人資料**：
使用者透過首頁「設定」維護已確認個人資訊的常駐區域。Phase 1 只包含可選且可移除的暱稱；未來欄位必須等需求確定後再加入，不預先建立空欄位或通用資料模型。
_Avoid_：音訊設定、預建使用者檔案

**完成日**：
存在一筆已成功儲存之完整四組訓練紀錄的日曆日。只完成計時但尚未儲存成功，不足以成為完成日。
_Avoid_：打卡日、成功日

**每日訓練**：
與一個日曆日關聯、可建立完成日的固定訓練；當日只有第一次完整完成會建立日曆紀錄。
_Avoid_：每日打卡、訓練次數

**不記錄訓練**：
進入訓練畫面時即固定不產生完成紀錄的既有四組 Tabata 流程。再次訓練及今日紀錄無法讀取時由使用者選擇直接開始的訓練都屬於此概念；完成、取消或保存錯誤皆不改變任何完成日。
_Avoid_：未保存完成、暫存訓練、每日訓練

**再次訓練**：
今日已成為完成日後，由「再做一次」進入的不記錄訓練；進入時即固定為不記錄，即使停在準備頁跨日後才開始也不會改成每日訓練。它不是忙碌模式、單組訓練或可累積的訓練 session。
_Avoid_：追加完成、第二次打卡、額外紀錄

**歸屬日**：
一筆每日訓練紀錄所屬的固定日曆日；使用者按下計時畫面的「開始」、進入 3 秒準備倒數時，以裝置當地日期鎖定並以 `local_date` 保存。單純進入訓練畫面不鎖定日期；準備或正式訓練期間跨午夜、裝置時區或所在地改變都不會重新歸類。
_Avoid_：UTC 日期、目前所在地日期

**目前時區完成時間**：
將 UTC `completed_at` 依查看當下的裝置時區轉換後顯示的日期與時間。它只用於閱讀，不決定歸屬日；跨時區時可能與歸屬日不同，UI 必須標示「目前時區」。
_Avoid_：原完成地時間、歸屬時間

**安全暫停**：
準備倒數或正式計時期間，App 失去前景時立即停止推進；同時暫停內建音樂、停止待播語音與提示並解除 Ducking，但不暫停第三方音樂。返回前景後維持暫停，由使用者選擇繼續或取消。狀態只保留於目前執行記憶體，App 被終止後不恢復，也不產生完成紀錄。
_Avoid_：背景計時、中斷恢復、自動續跑

**準備倒數**：
使用者按下計時畫面的「開始」後、正式訓練前的固定 3 秒倒數。它不屬於 110 秒 Tabata 訓練，也不計入完成門檻；期間返回或取消可直接離開，不顯示確認。
_Avoid_：第一階段、訓練時間

**導引語音**：
訓練流程中於階段邊界播放的九個 `zh-TW` 離線人聲短句，用來告知準備、運動、休息、組次與完成；不逐秒朗讀倒數，也不是連續教學旁白。
_Avoid_：提示音、背景音樂

**背景音樂**：
由 App 隨安裝包提供、受「背景音樂」偏好控制的一首離線循環音軌；與導引語音及階段提示音是不同概念。選曲、授權、證據與發布門檻的唯一正式定義見 `PRODUCT_SPEC.md` 第 3.7.2 節（原第 5.10 節「背景音樂選取與發布規則」）。
_Avoid_：導引語音、階段提示音

**Ducking**：
「背景音樂」開啟時，導引語音或重要提示播放期間暫時降低 App 內建音樂音量；關閉時，短語音／提示播放期間以 `duckOthers` 暫時降低第三方音樂音量。提示結束後必須恢復；不得將 Ducking 實作成永久停止。
_Avoid_：靜音、暫停音樂

**階段提示音**：
階段結束前協助使用者預判切換的短音效。準備倒數在 `3、2、1` 各播放一聲準備倒數音；每個運動／休息階段在剩餘 5、4、3、2、1 秒時連續播放同款階段倒數提示音，取消原 321 獨立倒數音。階段切換本身由導引語音告知，不再疊加喇叭聲；完成語音後另播放一次較明亮的完成音效。
_Avoid_：導引語音、逐秒語音

**音訊偏好**：
保存在本機的三個獨立布林設定：導引語音、提示音效、內建背景音樂。從初始月曆頁首的設定 modal 編輯，三者初始值皆為開啟並在切換時立即保存，不需要確認或另按儲存；下一次進入訓練畫面時套用。不保存自訂音量，也不直接控制其他 App 的第三方播放器。
訓練畫面無法讀取偏好時，本次三項皆視為關閉且不顯示提示；這不等同於已成功讀取或改寫使用者設定。
即使依背景音樂發布降級規則移除音樂素材，設定 modal、資料庫與程式仍保留背景音樂偏好及相關能力。
_Avoid_：系統音量、第三方音樂設定

**訓練音訊**：
使用者進入訓練畫面後播放的媒體音訊。背景音樂可在正式開始前播放；導引語音與提示音仍依計時事件播放。只要對應音訊偏好為開啟，即使 iPhone 靜音開關啟用仍播放；實際響度由系統媒體音量控制。
_Avoid_：通知音效、鈴聲音量

**訓練陪伴角色**：
在訓練與完成畫面出現的同一個陪伴性角色，不承擔動作教學、倒數、組數或訓練狀態提示。
_Avoid_：動作教練、動作示範、跟做指示

**靜音降級**：
音訊資源載入或播放失敗時，本次訓練仍依視覺計時繼續。準備階段失敗只顯示一次非阻擋訊息；訓練中失敗不彈出視窗、不補播，也不影響完成紀錄。
_Avoid_：訓練失敗、取消訓練、音訊重試流程

**TDD 公開測試 seam**：
測試可透過穩定公開邊界輸入行為並觀察結果的位置。MVP 固定使用五個 seams：日期／月曆純函式、計時推導介面、completion repository、畫面公開互動、音訊協調邊界。每次只在一個已確認 seam 寫一個失敗的行為測試，再加入使其通過的最少實作；不測 private function、hook 內部 state 或 Expo 套件內部呼叫細節。
_Avoid_：測試私有實作、整批先寫測試、水平分層開發

**補位日期**：
月曆首週與末週為維持完整七日排列而顯示的上月或下月日期。它只提供日期脈絡，降低對比且不可點擊；動態週數月曆不顯示完全不含本月日期的多餘整列，月份切換只由月份控制操作進行。
_Avoid_：多餘空白週、本月日期、日期詳情入口

**首頁主要訓練操作**：
第一頁首頁依今日狀態顯示的訓練入口。今日待完成或今日為休息日時顯示「GO」並開始每日訓練；今日已完成時不顯示「GO」，改以「再做一次」進入不記錄訓練。
_Avoid_：固定顯示 GO、再次打卡、月曆主要操作、歷史補做、所選日期訓練

**分頁導覽**：
App 底部常駐的首頁與日曆兩個同層入口；切換只改變目前內容，不是垂直捲動位置，也不重設日曆月份或捲動位置。
_Avoid_：垂直分頁、側邊導覽、頁面捲動

**未來日期**：
裝置當地日期之後的本月日期。MVP 沒有未來計畫或可執行操作，因此不顯示完成狀態且不可點擊。
_Avoid_：今日待完成、日期詳情入口

**待儲存完成**：
使用者已跑完整段計時，但完成紀錄尚未成功寫入 SQLite 的暫時狀態。可在目前畫面重新儲存；放棄紀錄、離開畫面或終止 App 後即遺失，不會成為完成日。
_Avoid_：完成日、已記錄、待同步

**計時完成**：
固定四組訓練的計時已全部結束，不表示每日完成紀錄已成功儲存。完成語音與音效對應這個時點；一般每日訓練仍須儲存成功才成為完成日。
_Avoid_：已記錄、完成日

**今日待完成**：
今天尚未成為完成日、也未設定休息日的暫時狀態；日期結束後若仍沒有紀錄，成為無紀錄日。
_Avoid_：今日未完成、失敗

**無紀錄日**：
沒有已儲存訓練或休息紀錄的過去日曆日；即使曾落在挑戰期間，也不表示使用者沒有運動或未履行既定任務。
_Avoid_：未完成日、漏做日

**挑戰週期**：
從建立當地日起算的 7、14 或 30 個連續當地日。期間只允許一個挑戰，建立後不能中途取消，休息不延長結束日；結束後可於隔日建立下一個挑戰。
_Avoid_：可順延挑戰、月曆月份

**休息日**：
使用者於挑戰日當天設定，或於隔日補登的每日紀錄。兩種來源對外都稱為休息日，不算完成訓練；設定時間僅用來判斷取消期限。休息日仍可開始訓練；中途取消不改變休息日，歸屬於該日的完整訓練成功儲存則轉為完成日並退還休息額度，即使儲存時已跨午夜。
_Avoid_：事前休息、補登休息

**剩餘休息額度**：
一輪挑戰尚可設定的休息日次數，等於該週期的固定額度減去仍存在的休息日數。取消休息或以完成日取代休息日後，額度恢復。
_Avoid_：額外休息天數、可順延天數

**挑戰剩餘天數**：
從目前裝置當地日到進行中挑戰結束日，包含今天的日曆日數。開始日等於完整週期天數，最後一天為 1；挑戰結束隔天不再顯示。
_Avoid_：已完成天數、訓練完成天數

**連續訓練天數**：
截至今天或昨天，連續日期中成功儲存訓練的日數；休息日維持連續性但不增加日數，無紀錄日使連續性中斷。
_Avoid_：連續挑戰天數、休息天數

**挑戰結算**：
挑戰結束後的一次性判定，只在當下顯示「已完成」或「未完成」。依結算當時週期內每日完成與休息紀錄判定；結算一旦觸發便視為已處理，關閉 App 後不重顯，其後每日紀錄的合法變動也不改變結果或提供結果歷史。
_Avoid_：全勤、每日狀態、歷史挑戰結果
